# Belousov-Zhabotinsky Reaction Canvas

## 概要
化学振動反応（BZ反応）の時空間パターンを反応拡散方程式（オレゴネーターモデル）で数値積分し、螺旋波・ターゲット波をcanvasにリアルタイム描画するシミュレーター。

## 機能
- 200×200グリッドでのオレゴネーターモデル (2変数) 数値積分
- u濃度に基づくカラーマップ（青→シアン→黄→赤サイクル）
- ε（励起時定数）、f（化学量論係数）、拡散比、速度スライダー
- Resetボタン（ランダム初期化）
- Pause/Resumeボタン
- キャンバスクリックで興奮中心を追加
- FPS・ステップカウンター表示
- カラーマップ凡例
- BZ反応の解説パネル

## 使い方
1. ページを開くとシミュレーションが自動的に始まります
2. しばらく待つと螺旋波やターゲット波が現れます
3. キャンバスをクリックして新しい興奮中心を追加できます
4. スライダーでパラメータを変更して波のパターンを観察してください
5. Resetで新しいランダム初期状態からやり直せます
